# Configuration Supabase

## Méthode recommandée : Créer la table via SQL

1. Allez dans votre projet Supabase
2. Cliquez sur **SQL Editor** dans la barre latérale
3. Créez un nouveau query et collez ce SQL :

```sql
CREATE TABLE questionnaire_responses (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nickname VARCHAR(255) NOT NULL,
  score INTEGER NOT NULL,
  total_questions INTEGER NOT NULL,
  percentage INTEGER NOT NULL,
  internal_score INTEGER NOT NULL,
  answers JSONB NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Activer Row Level Security (RLS)
ALTER TABLE questionnaire_responses ENABLE ROW LEVEL SECURITY;

-- Permettre les insertions publiques (pour l'application)
CREATE POLICY "Allow public insert" ON questionnaire_responses
  FOR INSERT
  TO anon
  WITH CHECK (true);

-- Permettre la lecture publique (optionnel, si vous voulez voir les données)
CREATE POLICY "Allow public select" ON questionnaire_responses
  FOR SELECT
  TO anon
  USING (true);
```

4. Cliquez sur **Run** pour exécuter

## Méthode alternative : Créer la table manuellement via l'interface

1. Allez dans **Table Editor** → **New table**
2. Nommez la table : `questionnaire_responses`
3. Ajoutez les colonnes suivantes :

| Name | Type | Default | Primary Key |
|------|------|---------|-------------|
| id | int8 | (auto-generated) | ✅ |
| nickname | varchar | - | - |
| score | int4 | - | - |
| total_questions | int4 | - | - |
| percentage | int4 | - | - |
| internal_score | int4 | - | - |
| answers | jsonb | - | - |
| created_at | timestamptz | now() | - |

4. Cliquez sur **Save**
5. Allez dans **Authentication → Policies** et ajoutez une politique pour permettre les insertions publiques

## Obtenir les credentials Supabase

1. Allez sur [supabase.com](https://supabase.com)
2. Créez un nouveau projet ou utilisez un existant
3. Allez dans **Settings → API**
4. Copiez :
   - **Project URL** (ex: https://xxx.supabase.co)
   - **anon/public key** (ex: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...)

## Utilisation dans l'application

1. Lancez le questionnaire
2. Répondez à toutes les questions
3. Après voir les résultats, entrez :
   - L'URL du projet Supabase
   - La clé API anon/public
4. Cliquez sur "Envoyer à Supabase"

Les données seront stockées dans la table `questionnaire_responses` avec :
- `score`: nombre de bonnes réponses
- `total_questions`: nombre total de questions
- `percentage`: pourcentage de réussite
- `answers`: JSON détaillé de chaque réponse (question, réponse utilisateur, bonne réponse, correct/incorrect)
- `created_at`: timestamp de l'envoi
